# Customer Segmentation using K-Means Clustering

## 📖 About the Project
This project focuses on customer segmentation using the K-Means Clustering algorithm. The objective is to group customers with similar purchasing behaviour based on their annual income and spending score. These customer groups help businesses understand buying patterns and create targeted marketing strategies.

---

## 🎯 Business Problem
Shopping malls have customers with different purchasing habits. Identifying customer groups manually is difficult. This project applies machine learning to automatically segment customers into meaningful clusters for better business decisions.

---

## 📂 Dataset
**Dataset Name:** Mall Customers Dataset

**Features Used**
- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1–100)

---

## 🤖 Machine Learning Algorithm
### K-Means Clustering
K-Means is an unsupervised machine learning algorithm that groups similar data points into clusters. In this project, the Elbow Method is used to determine the optimal number of customer clusters.

---

## 📈 Project Workflow
1. Import required libraries.
2. Load the Mall Customers dataset.
3. Explore and analyse the dataset.
4. Select important features.
5. Apply the Elbow Method to find the optimal number of clusters.
6. Train the K-Means model.
7. Assign cluster labels to customers.
8. Visualise customer clusters using scatter plots.
